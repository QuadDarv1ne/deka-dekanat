# Сверка со старым проектом

Проверка от 8 ноября 2026. Источник: `deka-dekanat-main.zip` из «Загрузок». Изучены API-маршруты, компоненты кабинета, генерация QR, расписание, оценки, профиль, объявления, уведомления, резервирование и помощник.

| Функция старого проекта | В новой Деке |
| --- | --- |
| Быстрый вход | Три указанных студента и роли сотрудников; доступ только на localhost с явной настройкой |
| QR студенческого | Отдельный раздел, постоянный номер, QR со случайной ссылкой, скачивание SVG и QR PNG, печать |
| Проверка студенческого | Авторизованный сотрудник, проверка факультета или закреплённой группы, блокировки аккаунта и запись в журнал |
| Справки и QR выдачи | Заявления со статусами, история, печатный экземпляр с QR, проверка записи в реестре |
| Расписание | Личный просмотр, ввод, изменение, перенос, отмена и восстановление, проверка пересечений |
| Экзамены | Типы «Экзамен» и «Зачёт» в общем расписании и импорте |
| ICS | Экспорт доступного пользователю расписания с корректным UTC и переносом длинных строк |
| Успеваемость | Текущий балл по дисциплине, оценка, прогресс и место в группе |
| Детальные работы и весовая БРС | Не копировались без согласованных правил вуза; текущая версия хранит итоговый результат дисциплины |
| Реестр студентов | Поиск по имени, группе и почте; факультет и преподавательские назначения ограничивают выборку |
| Объявления деканата | Публикация и удаление, уведомления студентам и преподавателям факультета |
| Уведомления | Личный список, прочтение отдельного уведомления при открытии и прочтение всех |
| Импорт учебных данных | CSV/XLSX, предпросмотр до записи, транзакционное подтверждение и защита от повтора |
| Чат | Локальная модель, сохранённая история, обычные учебные вопросы и серверное время |
| Установка приложения | Manifest, значки, service worker, активация обновления после закрытия вкладок |
| Offline | Кеш статических ресурсов и экран отсутствия сети; персональные ответы и страницы не кешируются |
| JSON backup/restore из профиля | Заменён резервной копией PostgreSQL. Массовое восстановление через пользовательский экран не переносилось |
| Тёмная тема | Не переносилась: новая утверждённая визуальная система остаётся светлой |

Старые React/Next-компоненты и самодельный JSON-реестр не копировались в новый код. Перенесены сценарии, данные остаются в PostgreSQL. Существующая локальная база сохранена; заменены только имена трёх учётных записей для быстрого входа.
